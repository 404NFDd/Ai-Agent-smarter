# AGENTS.md

모든 문서와 응답은 반드시 필요할 때를 제외하고 한글로 작성한다.

이 파일은 전역 Codex 작업 원칙이다. 프로젝트별 세부 규칙이 있으면 해당 프로젝트의 `AGENTS.md`를 함께 따른다.

## 1. 구현 전 생각하기

- 가정을 명시한다.
- 해석이 여러 개라면 후보를 제시한다.
- 불확실한 부분은 질문한다.
- 더 단순한 접근이 있으면 먼저 말한다.

## 2. 단순함 우선

- 요청받지 않은 기능은 추가하지 않는다.
- 한 번만 쓰는 코드를 위해 추상화를 만들지 않는다.
- 기존 스타일을 우선한다.
- 과도한 에러 처리나 설정 가능성을 만들지 않는다.

## 3. 외과적 변경

- 반드시 필요한 파일과 줄만 수정한다.
- 관련 없는 리팩터링을 하지 않는다.
- 내가 만든 unused 항목은 정리한다.
- 기존에 이미 있던 unrelated 변경은 되돌리지 않는다.

## 4. 목표 중심 실행

- 작업을 검증 가능한 목표로 바꾼다.
- 버그 수정은 가능하면 재현과 검증을 포함한다.
- 큰 작업은 짧은 계획을 먼저 제시한다.

계획 형식:

```text
1. [단계] -> 검증: [확인 방법]
2. [단계] -> 검증: [확인 방법]
3. [단계] -> 검증: [확인 방법]
```

## 5. Codex 운영 시스템

큰 작업에서는 다음 파일을 우선 사용한다.

- `PLAN.md`: 무엇을 만들지와 진행 순서
- `CONTEXT.md`: 결정 이유, 관련 파일, 제약 조건
- `CHECKLIST.md`: 완료 항목과 남은 항목
- `QA.md`: 검증 명령, 결과, 실패와 남은 위험

작업 시작 전 관련 memory 파일과 프로젝트 지침을 확인한다.
계획이 필요한 작업은 바로 구현하지 말고 먼저 계획을 요약한다.
작업 중 체크리스트를 갱신한다.
작업 완료 전 `CHECKLIST.md`와 `QA.md` 기록을 확인한다.
