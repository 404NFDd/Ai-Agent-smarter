# AGENTS.md

모든 문서와 응답은 반드시 필요할 때를 제외하고 한글로 작성한다.

이 파일은 이 프로젝트의 Codex 작업 규칙이다. 전역 `AGENTS.md`보다 프로젝트별 규칙이 더 구체적이면 프로젝트 규칙을 우선한다.

## 프로젝트 기본 규칙

- 요청받지 않은 기능을 추가하지 않는다.
- 기존 스타일과 폴더 구조를 우선한다.
- 관련 없는 리팩터링을 하지 않는다.
- 불확실한 요구사항은 구현 전에 질문한다.

## 작업 전

- `.codex-memory/PLAN.md`, `CONTEXT.md`, `CHECKLIST.md`를 확인한다.
- 관련 skill이 있으면 먼저 확인한다.
- 큰 작업이면 계획과 검증 기준을 먼저 요약한다.

## 작업 중

- 한 번에 한두 개 체크리스트 항목만 처리한다.
- 완료한 항목은 즉시 `CHECKLIST.md`에 반영한다.
- 중요한 결정과 이유는 `CONTEXT.md` 또는 `DECISIONS.md`에 기록한다.

## 작업 완료 전

- 수정 파일을 확인한다.
- 관련 테스트 또는 검증 명령을 실행한다.
- 실행한 검증과 남은 위험을 `QA.md`에 기록한다.
- 최종 보고에는 수정한 것, 검증한 것, 남은 위험을 포함한다.

## 프로젝트별 검증 명령

검증 명령은 `.codex/verify.toml`에 둔다. lint, test, typecheck, build 각 항목의
`command`를 대상 프로젝트 실제 명령으로 채운다. 빈 문자열이거나 `enabled = false`인
항목은 건너뛴다. stop_guard.ps1이 Stop 시점에 이 파일을 실행해 결과를
`.codex-memory/QA.md`에 기록하고 실패 시 종료를 block 한다.

## 역할별 검토 기준

- 큰 구조 변경 후에는 reviewer 검토를 사용한다.
- 테스트 실패 수정이나 검증 누락 점검에는 tester 검토를 사용한다.
- 인증, 권한, 입력 검증, 비밀정보 변경에는 security-reviewer 검토를 사용한다.
