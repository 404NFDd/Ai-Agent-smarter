# Codebase Onboarding Skill

## 목표

새 코드베이스를 빠르게 이해하되, 편집보다 관찰을 먼저 한다. 사용자가 구현을 명시하지 않았다면 구조와 실행 방법을 정리하는 데 집중한다.

## 함께 적용하는 스킬

- 큰 작업으로 이어지면 `../implementation-planning/SKILL.md`를 함께 적용한다.
- 실행/검증 명령을 확인할 때는 `../testing-qa/SKILL.md`를 함께 적용한다.
- 문서 구조를 정리할 때는 `../documentation/SKILL.md`를 함께 적용한다.

## 작업 전 확인

- 루트 `AGENTS.md`와 하위 디렉터리의 추가 지침을 먼저 확인한다.
- `.codex-memory`가 있으면 `PLAN.md`, `CONTEXT.md`, `CHECKLIST.md`, `DECISIONS.md`, `QA.md` 순서로 확인한다.
- `README`, `docs/`, 패키지 매니저 파일, 빌드 설정, 테스트 설정을 확인한다.
- `rg --files`로 파일 구조를 먼저 보고, 필요한 파일만 좁혀서 읽는다.

## 파악 순서

- 프로젝트 목적과 주요 사용자 흐름을 한두 문장으로 요약한다.
- 언어, 프레임워크, 패키지 매니저, 실행 명령, 테스트 명령 후보를 찾는다.
- 진입점, 라우팅, 주요 모듈, 데이터 저장소, 외부 서비스 경계를 확인한다.
- 기존 코드 스타일과 디렉터리 소유권을 파악한다.
- 불확실한 부분은 추측으로 확정하지 말고 후보와 근거를 함께 남긴다.

## 금지

- 온보딩만 요청받았는데 파일을 수정하지 않는다.
- 전체 파일을 무작정 읽지 않는다.
- 실행 명령을 확인하지 않고 특정 도구나 프레임워크라고 단정하지 않는다.

## 완료 전

- 파악한 실행/검증 명령을 `CONTEXT.md` 또는 답변에 남긴다.
- 다음 작업에 필요한 미확인 사항을 짧게 정리한다.
