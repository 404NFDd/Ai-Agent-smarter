# Frontend Skill

## 작업 전 확인

- 기존 디자인 시스템, 컴포넌트, spacing, 색상 규칙을 확인한다.
- 모바일과 데스크톱에서 깨질 수 있는 영역을 확인한다.
- 접근성에 영향을 주는 버튼, 폼, 모달 변경인지 확인한다.

## 금지

- 랜딩 페이지가 아닌 작업에 마케팅식 hero 구성을 추가하지 않는다.
- 기존 UI 톤과 무관한 장식 요소를 추가하지 않는다.
- 텍스트가 버튼이나 카드 밖으로 넘치게 두지 않는다.

## 완료 전

- lint 또는 build를 실행한다.
- 가능하면 브라우저로 주요 화면을 확인한다.
- 수동 확인이 남으면 `QA.md`에 명시한다.
