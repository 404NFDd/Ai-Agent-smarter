---
description: 방금 끝낸 작업을 CHECKLIST 에 반영하고 다음 항목을 정리한다.
allowed-tools: Read, Edit, Bash
---

방금까지 한 작업을 정리한다.

1. `.claude-memory/CHECKLIST.md` 에서 완료한 항목을 `- [x]` 로 바꾼다.
2. 작업 중 새로 생긴 할 일이 있으면 `- [ ]` 로 추가한다.
3. 중요한 결정을 했다면 `.claude-memory/DECISIONS.md` 에 `일시 / 결정 / 이유` 한 줄을 추가한다.
4. 남은 항목 중 다음에 할 한두 개를 지목한다.

한 번에 한두 개 항목만 진행한다. 남은 항목을 한꺼번에 처리하지 않는다.
