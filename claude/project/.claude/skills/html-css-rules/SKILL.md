# HTML CSS Rules Skill

- HTML 또는 CSS를 새로 작성하거나 수정하기 전에 `references/html-css-rules.md`를 읽고 그 지침을 적용한다.
- 참조 문서는 원문 그대로 보관한다. 필요한 작업에서만 읽어 불필요한 컨텍스트 사용을 막는다.
- 화면 흐름, 접근성, 컴포넌트 동작까지 함께 바뀌면 `../frontend-ui/SKILL.md`를 함께 적용한다.
